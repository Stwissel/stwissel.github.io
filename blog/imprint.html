Tools I use

  • This blog serves static pages from Cloudflare Workers static assets
  • Blog articles are created using Markdown and stored in a GitHub repository. On new content creation a GitHub Action renders the blog entries and index pages using Java and Mustache
  • Comments are captured by an endpoint on this site that submits a file to GitHub and creates a Pull Request that I need to approve (contemplating to automate that) to be added to the static pages
    • Comment entry is based on Markdown by John Gruber
  • Graphics are created with SmartDraw, Omnigraffle or Sketch
  • Wireframes are created with Balsamiq Mockups
  • Sequence diagrams use WebSequenceDiagrams or PlantUML
  • Image manipulation is done by The Gimp
  • The mindmaps are either iMindMap by Tony Buzan or XMind, the living prove, that Eclipse RCP applications can perform well
  • Layout is based on Twitter Bootstrap
